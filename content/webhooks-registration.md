# Webhook subscriptions

Create and manage webhook subscriptions through the V2 API. The API key determines whether the subscription covers one merchant or the complete account.

## Create a subscription

```http
POST https://api.sandbox.dinaria.com/v2/webhooks
Authorization: Bearer <YOUR_API_KEY>
Content-Type: application/json
```

```json
{
  "url": "https://merchant.example/webhooks/dinaria",
  "eventTypes": [
    "payout.created",
    "payout.status_changed"
  ]
}
```

`eventTypes` is optional:

- Omit it to receive every current and future V2 event.
- Send an explicit list to create a stable allowlist.
- Wildcards are not supported; use exact documented event names.

The response returns the signing secret only when the subscription is created or its secret is rotated:

```json
{
  "webhookId": "6c3fc750-8640-4a4f-b981-9ccfabd8f8c7",
  "url": "https://merchant.example/webhooks/dinaria",
  "apiVersion": "2",
  "scope": "merchant",
  "eventTypes": [
    "payout.created",
    "payout.status_changed"
  ],
  "creationDate": "2026-09-14T21:00:00Z",
  "updatedDate": "2026-09-14T21:00:00Z",
  "webhookSecret": "whsec_example_secret"
}
```

Store `webhookSecret` in a secret manager. It is not returned by list or update operations.

## Scope

| API key | Subscription scope |
|---|---|
| Merchant-scoped | Events for the merchant identified by the credential. |
| Account-scoped | Events for merchants visible to the authenticated account. |

Every event includes `merchantId`, allowing account-level consumers to route it correctly.

## List subscriptions

```http
GET https://api.sandbox.dinaria.com/v2/webhooks
Authorization: Bearer <YOUR_API_KEY>
```

```json
{
  "data": [
    {
      "webhookId": "6c3fc750-8640-4a4f-b981-9ccfabd8f8c7",
      "url": "https://merchant.example/webhooks/dinaria",
      "apiVersion": "2",
      "scope": "merchant",
      "eventTypes": [
        "payout.created",
        "payout.status_changed"
      ],
      "creationDate": "2026-09-14T21:00:00Z",
      "updatedDate": "2026-09-14T21:00:00Z"
    }
  ]
}
```

## Update a subscription

```http
PATCH https://api.sandbox.dinaria.com/v2/webhooks/{webhookId}
Authorization: Bearer <YOUR_API_KEY>
Content-Type: application/json
```

```json
{
  "url": "https://merchant.example/webhooks/dinaria-v2",
  "eventTypes": []
}
```

You can update `url`, `eventTypes`, or both. An empty `eventTypes` array removes the filter and subscribes the URL to all V2 events.

## Rotate the signing secret

```http
POST https://api.sandbox.dinaria.com/v2/webhooks/{webhookId}/rotate-secret
Authorization: Bearer <YOUR_API_KEY>
```

The response includes the new `webhookSecret`. The previous secret remains valid for 24 hours, so receivers should temporarily accept signatures generated by either active secret.

## Delete a subscription

```http
DELETE https://api.sandbox.dinaria.com/v2/webhooks/{webhookId}
Authorization: Bearer <YOUR_API_KEY>
```

A successful deletion returns `204 No Content`.
